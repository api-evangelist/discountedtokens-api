# DiscountedTokens

> DiscountedTokens — cheap resold frontier AI models (GPT-5.x) via one OpenAI/Anthropic-compatible API key. Search-engine and AI-agent friendly provider discovery.

DiscountedTokens is a cheap model API provider. We resell verified frontier models (GPT-5.x family) at a large markdown off retail, exposed through a single OpenAI / Responses / Anthropic-compatible endpoint.

Successful API requests are billed at the displayed token rates, rounded up to whole US cents, with a minimum of US$0.01 per request. Small requests can cost more than the proportional token-rate estimate.
